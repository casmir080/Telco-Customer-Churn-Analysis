# Telco-Customer-Churn-Analysis


Data Science & Power BI project predicting telecom customer churn and retention using Python and machine learning. Includes full workflow: data cleaning, EDA, modeling, and interactive Power BI dashboard with custom themes. Focused on actionable insights to reduce churn and improve customer lifetime value. Overview

This project analyzes customer churn behavior in a telecom company using Python for data science and Power BI for visualization. The goal is to identify key factors driving churn, predict at-risk customers, and design actionable retention strategies.

Project Objectives

Understand why customers leave the service (churn drivers). Identify high-value customers with churn risk. Build data-driven retention strategies. Create an interactive Power BI dashboard for business decision-making.

Features Data cleaning and preprocessing using Python (Pandas, NumPy). Exploratory Data Analysis (EDA) with visual insights (Matplotlib, Seaborn). Predictive modeling (Logistic Regression, Random Forest, XGBoost). Customer segmentation for targeted retention. Power BI dashboard showing churn KPIs, demographics, and trends.

Key Insights

Month-to-month customers have the highest churn rate. Fiber optic users churn more than DSL users. Electronic check payment method strongly correlates with churn. Long-term contracts significantly reduce churn probability. Targeted retention for customers with tenure < 12 months can reduce churn by ~25%.
